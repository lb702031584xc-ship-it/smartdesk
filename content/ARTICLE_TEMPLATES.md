# Affiliate article templates

See [CONTENT_ARCHITECTURE.md](./CONTENT_ARCHITECTURE.md) for the full CMS design.

Quick reference — set `type` in frontmatter:

| Type | Value | Example |
|---|---|---|
| Best X ranking | `best` | `/blog/best-standing-desks-small-apartments` |
| Product review | `review` | `/blog/flexispot-compact-standing-desk-review` |
| Product comparison | `comparison` | `/blog/standing-desk-vs-writing-desk` |

Products are referenced by ID from `content/products/*.json`.
